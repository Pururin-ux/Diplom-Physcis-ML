# Novelty assessment (frozen outcomes E1-E4)

## E1 - CANONICAL EVENT PROCESS VALIDATED: YES

- Event enumeration is exact and complete (telescoping residual 0.0 over all 32
  placements).
- Telescoping identities hold for E_j, gap, and center.
- Marks are basis/transport/gauge independent (eigenvalues only); the
  construction needs no compression, transport, or embedding (unlike the
  withdrawn Article-Ib response matrix).
- The finite-rank secular-equation / interlacing formulas reproduce the event
  mechanics (toy-verified).
This is a genuine, well-posed object. It is NOT itself a novelty (E1 is
explicitly "not yet novelty").

## E2 - KNOWN FINITE-RANK / DISCREPANCY PHYSICS: YES (this is the operative status)

- The per-event shift is a finite-rank perturbation; its mechanism is the Schur
  secular equation / Krein spectral shift / Cauchy interlacing (all textbook).
- Bare geometric counting is insufficient for the gap mark (R^2 = 0.41) exactly
  because a finite-rank shift is a matrix element, not a count.
- The eigenfunction-weighted marks that raise the gap-mark R^2 to 0.91 ARE that
  known matrix element (Schur self-energy / boundary-deformation matrix element,
  Barnett-Cohen-Heller); they are in the literature gate.
- The geometric event process itself is lattice-point discrepancy (Brandolini
  et al.), known.
So the marks are explained by known finite-rank + discrepancy physics; the
eigenfunction weighting adds the KNOWN matrix-element structure, not structure
beyond it.

## E3 - EIGENFUNCTION-WEIGHTED EVENT STRUCTURE (potentially novel): NOT MET

E3 requires (i) bare counting insufficient [TRUE], (ii) spectral weights add
reproducible structure [TRUE], (iii) reproducible across placements/sizes
[TRUE], AND (iv) no direct literature analog [FALSE]. Condition (iv) fails: the
direct analog is the Schur self-energy / Krein spectral shift / boundary matrix
element. So this is not a novelty candidate. A true E3 would need marks
structure that the finite-rank + discrepancy prediction does NOT capture; none
is shown.

## E4 - EVENT OBJECT NOT USEFUL: NO

The object is well-defined, reproducible, and mechanistically transparent; E4
does not apply.

## Conclusion

E1 (validated) + E2 (known physics). The canonical event formulation is a sound
methodological object, but the physics is textbook finite-rank perturbation plus
geometric lattice-point discrepancy, with the eigenfunction weight being the
known matrix element. No separate physical novelty is established, and none is
likely without a demonstrated deviation from the known finite-rank/discrepancy
prediction.
