# Предрегистрация: соизмеримость стоячих волн как объяснение нулевых мод

Записано **до** сверки с численными расчётами. Аналитический вывод в
разделе 2 получен карандашом, из известного точно решаемого предела, без
обращения к коду и без просмотра ранее посчитанных таблиц.

Причина этой предрегистрации: в предыдущей итерации объяснение искалось
через ранг целочисленной матрицы и паросочетания на двудольном графе, минуя
простейшую возможность — точно решаемый прямоугольный предел. Протокол
требует обратного порядка.

---

## 1. Физический вопрос

Почему у чистого квадратно-решёточного бильярда с жёсткими стенками в
середине зоны (`E = 0`) возникает большое вырождение, и чем оно
определяется?

## 2. Основная гипотеза: условие соизмеримости

Для прямоугольного ящика `Lx x Ly` переменные разделяются, и

    E(m, n) = -2 [ cos(pi*m/(Lx+1)) + cos(pi*n/(Ly+1)) ],
    m = 1..Lx,  n = 1..Ly.

Условие `E = 0` означает `cos(alpha) = -cos(beta)`, то есть
`alpha + beta = pi` (косинус инъективен на интервале `(0, pi)`), то есть

    m/(Lx+1) + n/(Ly+1) = 1.

Физический смысл: нулевая мода появляется, когда полуволна вдоль `x` и
полуволна вдоль `y` **соизмеримы** так, что их вклады в энергию точно гасят
друг друга. Это резонансное условие, а не свойство графа.

Счёт целых решений. Пусть `P = Lx+1`, `Q = Ly+1`, `d = gcd(P, Q)`,
`P = d*p`, `Q = d*q` с взаимно простыми `p, q`. Уравнение `m*Q + n*P = P*Q`
переходит в `m*q + n*p = d*p*q`. Так как `gcd(p, q) = 1`, получаем
`m = p*j` и `n = q*(d - j)`, а границы `1 <= m <= Lx`, `1 <= n <= Ly` дают
`j = 1..d-1`. Отсюда

    M_прямоугольника = gcd(Lx + 1, Ly + 1) - 1.                        (П1)

Частный случай квадрата `L x L`:

    M_квадрата = L,                                                    (П2)

то есть **число нулевых мод квадрата равно числу его столбцов**.

**Гипотеза H1 (деформационная).** Для центрированной выпуклой области с
симметрией четвёртого порядка, занимающей `L` столбцов решётки, число
нулевых мод равно `L` — то же, что у квадрата `L x L`. Иначе говоря,
непрерывная деформация квадрата в круг и в ромб с сохранением симметрии
четвёртого порядка не меняет числа нулевых мод.

## 3. Альтернативные гипотезы

- **A1. Чисто симметрийная.** Число нулевых мод определяется разложением по
  неприводимым представлениям группы симметрии области, а форма границы и
  выпуклость не важны. *Предсказание:* невыпуклые области с симметрией
  четвёртого порядка подчиняются тому же правилу.
- **A2. Структурная (паросочетания).** Вырождение задаётся дефицитом
  максимального паросочетания двудольного графа. *Предсказание:*
  алгебраическая кратность равна `N - 2*nu`.
- **A3. Численная погрешность.** Часть «нулевых» уровней — экспоненциально
  малые, но ненулевые числа. *Предсказание:* кратность зависит от порога и
  от разрядности арифметики.
- **A4. Тривиальность.** Правило (П2) для квадрата — учебный факт, а H1 либо
  тоже известна, либо элементарно следует из (П1) предельным переходом.

## 4. Измеряемая величина

Размерность ядра гамильтониана `dim ker H` — целое число. Сравнивается с
аналитическим предсказанием (П1) для прямоугольников и с `L` для
деформированных областей с симметрией четвёртого порядка.

## 5. Контрольные расчёты

1. **Проверка известного (обязательна первой).** Прямые диагонализации
   прямоугольников против формулы (П1) на сетке `Lx, Ly = 2..40`. Формула
   выведена независимо, поэтому это настоящая проверка, а не подгонка.
2. **Численная устойчивость (против A3).** Сравнение подсчёта по порогу,
   по сингулярным числам и по точному рангу над конечными полями.
3. **Роль выпуклости (H1 против A1).** Невыпуклые области с симметрией
   четвёртого порядка: крест, «цветок» с большой амплитудой, кольцо.
4. **Роль симметрии.** Понижение симметрии до второго и третьего порядка при
   сохранении центрирования.
5. **Смена решётки и положения.** Сдвиг центра, поворот, изменение размера.

## 6. Критерии опровержения

- **H1 опровергнута**, если найдётся центрированная выпуклая область с
  симметрией четвёртого порядка и `L` столбцами, у которой `dim ker H != L`.
- **(П1) опровергнута**, если хотя бы для одного прямоугольника прямая
  диагонализация разойдётся с формулой.
- **A1 подтверждена вместо H1**, если правило удержится и для невыпуклых
  областей с симметрией четвёртого порядка. *По имеющимся данным ожидается,
  что A1 будет отвергнута: крест, кольцо и «цветок» с амплитудой 0.30 правилу
  не подчинялись. Это наблюдение уже сделано, поэтому засчитывать его как
  предсказание нельзя.*
- **A2 подтверждена вместо основной линии**, если алгебраическая кратность
  совпадёт с `N - 2*nu`.
- **A4 подтверждена**, если (П1) или её эквивалент обнаружатся в литературе
  как известный результат. Это ожидаемый исход для (П1).

## 7. Ближайшая известная литература

- Точный спектр прямоугольного двумерного tight-binding ящика с открытыми
  границами — учебный результат; в этом репозитории он уже реализован в
  `src/baseline.py::exact_rectangular_tb_levels`.
- Ulčakar & Vidmar, *Phys. Rev. E* **106**, 034118 (2022): нулевые моды в
  tight-binding бильярдах как киральные состояния на одной подрешётке.
- Bhola, Biswas, Islam & Damle, *Phys. Rev. X* **12**, 021058 (2022):
  избыточные нулевые моды на **разбавленных** двудольных решётках,
  объясняемые структурой максимальных паросочетаний.
- Спектр решёточного графа (декартова произведения двух путей) — стандартный
  результат спектральной теории графов; формулу вида (П1) следует искать
  именно там, а не в физической литературе.

## 8. Заранее оговорённые ограничения

- H1 сформулирована **после** просмотра расчётов предыдущей итерации,
  поэтому на тех же данных она не проверяется. Проверка допустима только на
  конфигурациях, которые ранее не считались.
- Отсутствие находок в поиске литературы не будет считаться доказательством
  новизны ни для (П1), ни для H1.
- Ожидаемый наиболее вероятный исход: (П1) — известный результат, H1 — либо
  известна, либо выводится из (П1) простым рассуждением. Работа считается
  успешной и в этом случае, потому что она заменяет непрозрачное
  алгебраическое наблюдение понятным физическим механизмом.
