# Презентация к защите диплома

Основной файл:

- `diploma_defense_6slides.pptx`

Презентация собрана в стиле предоставленного PPTX-шаблона БГУ: формат 16:9, Times New Roman, верхний заголовок, тёмно-синий номер слайда справа, академическая бело-синяя графика, подписи рисунков и таблиц в стиле шаблона.

## Как открыть

В Windows откройте:

```text
D:\Diplom Physcis ML\Diplom Physcis ML\thesis\presentation\diploma_defense_6slides.pptx
```

## Как пересобрать

Из корня репозитория:

```powershell
python thesis/presentation/build_defense_6slides.py
```

Скрипт использует предоставленный шаблон `Презентация (Сиротюк) (2).pptx`, если он доступен в папке загрузок Telegram Desktop. Если шаблон недоступен, презентация всё равно собирается с теми же размерами, шрифтами и координатной сеткой.

## Источники графики

Используются готовые рисунки из `reports/assets` и служебные схемы из `thesis/presentation/generated_assets`. Научные расчёты, CSV-отчёты и данные при сборке презентации не пересчитываются.

## PDF

Автоматический экспорт PDF в текущей среде недоступен, потому что PowerPoint COM/LibreOffice не установлены. PDF можно получить вручную через PowerPoint: `Файл -> Экспорт -> Создать PDF`.
